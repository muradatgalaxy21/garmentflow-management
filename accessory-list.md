# En En Garments — Accessories List
*Products: Shirts, Hoodies, Sweatshirts, Trousers, Shorts, Jackets, Parachute Jackets, Padded Sportswear*

## 1. Stitching / Sewing Accessories
- Thread (sewing thread — different colors/counts)
- Interlining/Fusing (collar, cuff, placket)
- Buttons (shirt buttons, jacket buttons)
- Snap buttons (hoodies/jackets)
- Zippers (jackets, hoodies — metal or plastic)
- Drawstring/Drawcord (hoodies, shorts)
- Drawcord end caps/aglets
- Elastic (shorts, trousers waistband)
- Velcro (jackets)
- Rivets (jackets, heavy trousers)
- Eyelets (hoodie strings, jackets)
- Piping/Cording (design trim)
- Shoulder pads (structural — jackets)
- Pocket bags/lining fabric (trousers, shorts)

## 2. Labels & Tags
- Main label (brand label — neck)
- Size label
- Care label (washing instructions)
- Composition label (fabric content)
- Country of origin label
- Hang tag (price/brand tag)
- Hang tag string/safety pin/plastic tag pin
- Barcode sticker

## 3. Packing Accessories
- Poly bags (individual packing)
- Tissue paper
- Cardboard/chipboard (collar support — shirts)
- Collar stand/butterfly clips
- Pins (T-pins, ballpoint pins)
- Stickers (size sticker, carton sticker)
- Master carton
- Inner carton/box
- Tape (carton sealing)
- Silica gel packets

## 4. Production Tracking / Misc
- Sequence tags/lot tags
- Waistband labels (trousers/shorts)
- Reflective trims (some jackets)

## 5. Parachute / Technical Jackets
- Waterproof zippers
- Taped seams/seam tape
- Toggle stoppers (drawcord lock — hood/waist)
- Hood (attached or detachable, snap-on)
- Mesh lining
- Ripstop tape/patches (repair/reinforcement)
- Storm flap (zipper cover — wind/rain protection)
- D-rings (chest/waist attachment)
- Reflective piping/trim (safety visibility)
- Elastic cuffs with thumbhole
- Water-repellent coating tag (DWR finish label)

## 6. Sportswear — Padding / Protective
- Knee pads (foam/EVA insert + fabric shell)
- Elbow pads
- Shoulder pads (protective — sportswear-specific)
- Chest pad/guard
- Compression panels (mesh/spandex inserts)
- Foam inserts (EVA foam, closed-cell foam)
- Pad pockets/sleeves (removable pad holders)
- Bonding tape (no-sew seam bonding)
- Silicone grippers (leg/arm cuffs — anti-slip)
