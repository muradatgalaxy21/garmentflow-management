# Project Instructions

## Attribution
- Never list yourself (Claude/Claude Code) as a contributor, author, or co-author anywhere: commit messages, PR descriptions, code comments, docs. No "Co-Authored-By: Claude" lines.

## Git / GitHub
- Push commits to the GitHub repo at the end of every session, and after completing each task within a session — don't let work sit unpushed.

## progress.md
- Update `progress.md` (repo root) every session: what got done, what's blocked, what's left before prod. Keep it current, don't let it go stale.
- Stamp every update with current date and time (e.g. `## 2026-07-27 16:42`) so history stays traceable across sessions.
